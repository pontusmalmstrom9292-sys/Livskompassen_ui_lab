# UI Laws

1. **Nästa mikrosteg först.**
2. **Max en primär handling per panel.**
3. **Minst 48 px touchyta.**
4. **Ingen funktion får en egen huvudvärld utan arkitekturbeslut.**
5. **Fyren styr komplexitet i bakgrunden.**
6. **Låg kapacitet ska minska synligt innehåll, inte bara visa en varning.**
7. **Färg används för riktning, inte dekoration.**
8. **Guld betyder aktivt eller viktigt.**
9. **Grönt används sparsamt för verkligt klart/godkänt.**
10. **Rött används endast vid faktisk risk eller destruktiv handling.**
11. **Låsta produktflöden får inte döljas eller tas bort av visuell konfiguration.**
12. **Nya mockups måste registreras och få status.**
